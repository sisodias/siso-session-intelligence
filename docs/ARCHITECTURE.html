SISO Session Intelligence

An evidence-backed learning pipeline over explicitly supplied agent sessions. It belongs in the Agents → Shared intelligence projection, while remaining independently forkable and releasable.

Outcome and flow

explicit JSONL input
  → Claude/Codex adapter
  → normalized event contract
  → redact + bound text
  → append-only event identity
  → typed insight observations
  → recurrence + importance
  → local recall / JSON export

Privacy boundary: the repository and database never own raw transcripts. Input paths are explicit, absolute paths are not persisted, text is redacted before insertion, source/session locators are hashes, and the core performs no network request.

Why this is its own repository

Its outcome, privacy risk, data lifecycle, adapters, storage, and release cadence are coherent and different from Agent Runtime and Agent Brain. Runtime owns session execution and resume. Brain owns shared operational state. Session Intelligence learns from transcript evidence.

First release decisions

DecisionReason
Two provider adapters, one event contractProvider envelopes change without changing analysis or storage.
Explicit files onlyConsent and scope are visible; no surprise machine crawl.
Deterministic classification and scoringOffline, inspectable baseline before optional model extractors.
SQLite single-writer sourcePortable local state with one schema and machine-verifiable behavior.
No mutation engineLearning does not imply authority to alter code or agent policy.

Evolution contract

Future extractors, embeddings, or clustering algorithms must emit the same typed insight and evidence contracts. Raw-data retention must remain a separate explicit policy. A model-assisted extractor should be an adapter, never a credential-bearing global.

Evidence

script/test ingests synthetic Claude and Codex sessions, proves idempotence, checks recall and export, and searches the resulting database for material that should have been redacted. MIGRATION-MAP.json records every source disposition.
