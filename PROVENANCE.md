# Provenance

This repository is a clean public implementation of contracts read from the
untracked `extensions/session-mirror` material in SISO Agent Base at revision
`470226b133b753dafd6a675fb2714330f972e345`.

The warehouse directory was not copied or rewritten. It contained personal
machine paths, private data assumptions, generated state, and a credential-bearing
provider shim. The public source retains only the reusable behavior described in
`MIGRATION-MAP.json`, with synthetic fixtures and no provider dependency.

The warehouse repository's MIT license is carried forward for this SISO-owned
reimplementation. Raw transcripts and any third-party session content remain
outside this repository and retain their original rights and privacy obligations.
